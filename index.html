Set up your sign-in

One time only. Choose a password, and paste the GitHub key that lets this page manage your private posting project. The key is locked with your email and password before it's saved, so only you can sign in and use it.

At least 12 characters. A few random words together works well, e.g. "lemon-orbit-kettle-91".

How to make the GitHub key
  1. On github.com, click your profile picture → Settings → Developer settings (bottom of the left menu) → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "Grimmitt Social" and pick an expiry (a year is fine; you can replace it here later).
  3. Repository access: Only select repositories → monkey-vine-rush-social and grimmittgames-social.
  4. Repository permissions: set Actions, Contents and Secrets to Read and write.
  5. Click Generate token, copy it (it starts github_pat_) and paste it above.

          Credentials

          Each platform has its own tab (✓ = everything saved). Open "Where to find this" under any box for step-by-step help. They're encrypted in this browser and saved as GitHub secrets: nobody can read them back, not even here. Leave a box empty to keep what's already saved.           Back up and restore

          GitHub never shows saved credentials again, so the site keeps its own copy, encrypted with your sign-in password, whenever you save with the password above. Export it to keep somewhere safe; import it to fill every box again.

          Exporting and importing both need your sign-in password in the box above. The file stays encrypted: keep it somewhere private all the same.
