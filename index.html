Set up your sign-in

One time only. Choose a password, and paste the GitHub key that lets this page manage your private posting project. The key is locked with your email and password before it's saved, so only you can sign in and use it.

At least 12 characters. A few random words together works well, e.g. "lemon-orbit-kettle-91".

How to make the GitHub key
  1. On github.com, click your profile picture → Settings → Developer settings (bottom of the left menu) → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "Grimmitt Social" and pick an expiry (a year is fine; you can replace it here later).
  3. Repository access: Only select repositories → monkey-vine-rush-social and grimmittgames-social.
  4. Repository permissions: set Actions, Contents and Secrets to Read and write.
  5. Click Generate token, copy it (it starts github_pat_) and paste it above.

          Credentials

          Each platform needs its own keys. Open "Where to find this" under any box for step-by-step help. They're encrypted in this browser and saved as GitHub secrets: nobody can read them back, not even here. Leave a box empty to keep what's already saved. A platform starts posting once all of its boxes are saved.

          Schedule

          Each time below posts one video. Research suggests evenings suit gaming videos: about 7 to 9 pm for a UK audience.

          Platforms

          Leave this off unless the videos are aimed mainly at children: it turns off comments and some features on YouTube.

          AI captions

          Uses Claude (Anthropic) with your own API key (under Credentials). It writes fresh captions for every platform each time, following the platform research and your house style; it never calls players "monkeys" and keeps everything family-friendly. Each post costs a few pence. If AI isn't set up or fails, the standard captions are used.

          Captions

          Each post already has 3 to 5 hashtags matched to the video. Keep extras to one or two: a few relevant tags beat long lists.

          Order

          Videos post from the top. Move them up or down, or skip one.
